# String Patterns & Algorithms - Complete Deep Dive

## 🎯 Key Concepts

### What Are String Patterns?

**String patterns** are specialized algorithms and techniques designed to solve common string manipulation problems efficiently. Unlike general array patterns, string algorithms often exploit the sequential nature of characters and linguistic properties.

**Think of it like this:**

- **Pattern Matching**: "Find this needle in the haystack efficiently"
- **Palindrome Detection**: "Check if text reads the same forwards and backwards"
- **Anagram Detection**: "Do these words use the same letters?"
- **String Reversal**: "Flip characters or words in various ways"
- **Subsequence/Substring**: "Find common patterns between strings"
- **String Compression**: "Represent text more compactly"

**Why string patterns matter:**

- Turn O(n×m) brute force pattern matching into O(n+m) with KMP
- Solve complex substring problems in linear time
- Master Dynamic Programming through string problems (LCS, Edit Distance)
- Essential for text processing, DNA sequencing, search engines
- Frequently appear in coding interviews at all levels

## 🎯 Pattern Recognition Guide

### When to Use Which Pattern

| Pattern                 | Use When                                               | Complexity | Space  |
| ----------------------- | ------------------------------------------------------ | ---------- | ------ |
| **Two Pointers**        | Palindrome checks, string reversal, word manipulation  | O(n)       | O(1)   |
| **Sliding Window**      | Substring with constraints, longest/shortest substring | O(n)       | O(k)   |
| **Hash Map**            | Anagrams, character frequency, unique characters       | O(n)       | O(k)   |
| **KMP Algorithm**       | Pattern matching in text, finding all occurrences      | O(n+m)     | O(m)   |
| **Rabin-Karp**          | Multiple pattern matching, plagiarism detection        | O(n+m)     | O(1)   |
| **Manacher's**          | Longest palindromic substring (optimal)                | O(n)       | O(n)   |
| **Dynamic Programming** | Longest common subsequence/substring, edit distance    | O(n×m)     | O(n×m) |
| **Trie/Suffix Array**   | Multiple string searches, autocomplete                 | O(n)       | O(n)   |

## 1️⃣ Palindrome Detection

### 🎯 Core Concept

A palindrome reads the same forwards and backwards. Two main approaches:

1. **Two Pointers**: Compare characters from ends moving inward
2. **Expand Around Center**: For finding all palindromes

### Basic Palindrome Check

**Pattern:** Use two pointers from opposite ends

```
"racecar"
 ↓     ↓
 r === r ✓
  a = a ✓
   c=c ✓
    e (middle, done)
```

---

#### Problem 1: Valid Palindrome

**Given:** Check if string is palindrome (ignore non-alphanumeric, case-insensitive)

<details open>
<summary><b>Python</b></summary>

```python
def is_palindrome(s: str) -> bool:
    """
    Check if string is palindrome
    Time: O(n), Space: O(1)
    """
    left = 0
    right = len(s) - 1

    while left < right:
        # Skip non-alphanumeric characters
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1

        # Compare characters (case-insensitive)
        if s[left].lower() != s[right].lower():
            return False

        left += 1
        right -= 1

    return True

# Examples
print(is_palindrome("A man, a plan, a canal: Panama"))  # True
print(is_palindrome("race a car"))                       # False
print(is_palindrome(""))                                 # True
```

```javascript
function isPalindrome(s) {
  let left = 0;
  let right = s.length - 1;

  const isAlphaNumeric = (char) => /[a-z0-9]/i.test(char);

  while (left < right) {
    // Skip non-alphanumeric
    while (left < right && !isAlphaNumeric(s[left])) {
      left++;
    }
    while (left < right && !isAlphaNumeric(s[right])) {
      right--;
    }

    // Compare
    if (s[left].toLowerCase() !== s[right].toLowerCase()) {
      return false;
    }

    left++;
    right--;
  }

  return true;
}
```

#### Problem 2: Longest Palindromic Substring

**Given:** Find the longest palindromic substring in a string

**Approach:** Expand around each possible center

<details open>
<summary><b>Python</b></summary>

```python
def longest_palindrome(s: str) -> str:
    """
    Find longest palindromic substring
    Time: O(n²), Space: O(1)

    Strategy: Expand around each center
    - Odd length palindromes: single character center
    - Even length palindromes: two character center
    """
    if not s:
        return ""

    def expand_around_center(left: int, right: int) -> int:
        """Expand while characters match, return length"""
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return right - left - 1  # Length of palindrome

    start = 0
    max_len = 0

    for i in range(len(s)):
        # Check odd length palindrome (single center)
        len1 = expand_around_center(i, i)
        # Check even length palindrome (two centers)
        len2 = expand_around_center(i, i + 1)

        current_len = max(len1, len2)

        if current_len > max_len:
            max_len = current_len
            # Calculate start position
            start = i - (current_len - 1) // 2

    return s[start:start + max_len]

# Examples
print(longest_palindrome("babad"))      # "bab" or "aba"
print(longest_palindrome("cbbd"))       # "bb"
print(longest_palindrome("racecar"))    # "racecar"
print(longest_palindrome("abcdef"))     # "a" (any single char)
```

```javascript
function longestPalindrome(s) {
  if (!s) return "";

  function expandAroundCenter(left, right) {
    while (left >= 0 && right < s.length && s[left] === s[right]) {
      left--;
      right++;
    }
    return right - left - 1;
  }

  let start = 0;
  let maxLen = 0;

  for (let i = 0; i < s.length; i++) {
    const len1 = expandAroundCenter(i, i); // Odd length
    const len2 = expandAroundCenter(i, i + 1); // Even length

    const currentLen = Math.max(len1, len2);

    if (currentLen > maxLen) {
      maxLen = currentLen;
      start = i - Math.floor((currentLen - 1) / 2);
    }
  }

  return s.substring(start, start + maxLen);
}

console.log(longestPalindrome("cbbd")); // "bb"
```

</details>

**Why expand around center?**

```
String: "babad"

Center at index 0 ('b'):
  Odd:  b → length 1
  Even: b|a → different, length 0

Center at index 1 ('a'):
  Odd:  b-a-b → length 3 ✓
  Even: a|b → different, length 0

Center at index 2 ('b'):
  Odd:  a-b-a → length 3 ✓
  Even: b|a → different, length 0

Center at index 3 ('a'):
  Odd:  b-a-d → different, length 1
  Even: a|d → different, length 0

Best: "bab" or "aba" (both length 3)
```

## 2️⃣ Anagram Detection

### 🎯 Core Concept

Anagrams are words formed by rearranging letters. Two strings are anagrams if they contain the same characters with the same frequencies.

**Key Techniques:**

1. **Sorting**: Sort both strings and compare (O(n log n))
2. **Frequency Count**: Use hash map or array (O(n))

---

#### Problem 3: Valid Anagram

**Given:** Check if two strings are anagrams

<details open>
<summary><b>Python</b></summary>

```python
def is_anagram(s: str, t: str) -> bool:
    """
    Method 1: Using sorting
    Time: O(n log n), Space: O(1)
    """
    if len(s) != len(t):
        return False
    return sorted(s) == sorted(t)

def is_anagram_optimal(s: str, t: str) -> bool:
    """
    Method 2: Using frequency count
    Time: O(n), Space: O(1) - fixed charset (26 letters)
    """
    if len(s) != len(t):
        return False

    # Count character frequencies
    freq = {}
    for char in s:
        freq[char] = freq.get(char, 0) + 1

    for char in t:
        if char not in freq:
            return False
        freq[char] -= 1
        if freq[char] < 0:
            return False

    return True

# Using Counter (Pythonic way)
from collections import Counter

def is_anagram_counter(s: str, t: str) -> bool:
    """
    Method 3: Using Counter
    Time: O(n), Space: O(1)
    """
    return Counter(s) == Counter(t)

# Examples
print(is_anagram("anagram", "nagaram"))     # True
print(is_anagram("rat", "car"))             # False
print(is_anagram_optimal("listen", "silent"))  # True
```

```javascript
function isAnagram(s, t) {
  // Method 1: Sorting
  if (s.length !== t.length) return false;

  const sortStr = (str) => str.split("").sort().join("");
  return sortStr(s) === sortStr(t);
}

function isAnagramOptimal(s, t) {
  // Method 2: Frequency count
  if (s.length !== t.length) return false;

  const freq = new Map();

  for (const char of s) {
    freq.set(char, (freq.get(char) || 0) + 1);
  }

  for (const char of t) {
    if (!freq.has(char)) return false;
    freq.set(char, freq.get(char) - 1);
    if (freq.get(char) < 0) return false;
  }

  return true;
}
```

```python
def group_anagrams(strs: list[str]) -> list[list[str]]:
    """
    Group anagrams together
    Time: O(n * k log k) where n is number of strings, k is max length
    Space: O(n * k)

    Strategy: Use sorted string as key
    """
    from collections import defaultdict

    anagram_groups = defaultdict(list)

    for s in strs:
        # Use sorted string as key
        key = ''.join(sorted(s))
        anagram_groups[key].append(s)

    return list(anagram_groups.values())

def group_anagrams_optimal(strs: list[str]) -> list[list[str]]:
    """
    Optimal: Use character count as key
    Time: O(n * k), Space: O(n * k)
    """
    from collections import defaultdict

    anagram_groups = defaultdict(list)

    for s in strs:
        # Create frequency tuple as key (26 letters)
        count = [0] * 26
        for char in s:
            count[ord(char) - ord('a')] += 1

        # Tuple can be used as dict key
        key = tuple(count)
        anagram_groups[key].append(s)

    return list(anagram_groups.values())
```

## 3️⃣ Pattern Matching Algorithms

### 🎯 Core Concept

Pattern matching finds occurrences of a pattern string within a text string. The naive approach is O(n×m), but specialized algorithms achieve O(n+m).

---

### 3.1 Naive Pattern Matching

#### Problem 5: Basic Pattern Search

<details open>
<summary><b>Python</b></summary>

```python
def naive_pattern_search(text: str, pattern: str) -> list[int]:
    """
    Naive pattern matching - check every position
    Time: O(n × m) where n=len(text), m=len(pattern)
    Space: O(1) (excluding result)
    """
    n = len(text)
    m = len(pattern)
    positions = []

    # Check each possible starting position
    for i in range(n - m + 1):
        # Check if pattern matches at position i
        match = True
        for j in range(m):
            if text[i + j] != pattern[j]:
                match = False
                break

        if match:
            positions.append(i)

    return positions

# Example

print(naive_pattern_search(text, pattern))  # [0, 9, 12]
```

### 3.2 KMP (Knuth-Morris-Pratt) Algorithm

#### 🎯 Core Concept

KMP preprocesses the pattern to avoid redundant comparisons. It uses a "longest proper prefix which is also suffix" (LPS) array.

**Key Insight:** When a mismatch occurs, we already know some characters matched. Use this info to skip ahead!

<details open>
<summary><b>Python</b></summary>

```python
def kmp_search(text: str, pattern: str) -> list[int]:
    """
    KMP pattern matching
    Time: O(n + m) - linear!
    Space: O(m) - for LPS array
    """
    if not pattern:
        return []

    # Build LPS (Longest Proper Prefix which is also Suffix) array
    def compute_lps(pattern: str) -> list[int]:
        """
        LPS[i] = length of longest proper prefix of pattern[0..i]
                 which is also suffix of pattern[0..i]
        """
        m = len(pattern)
        lps = [0] * m
        length = 0  # Length of previous longest prefix suffix
        i = 1

        while i < m:
            if pattern[i] == pattern[length]:
                length += 1
                lps[i] = length
                i += 1
            else:
                if length != 0:
                    # Try shorter prefix
                    length = lps[length - 1]
                else:
                    lps[i] = 0
                    i += 1

        return lps

    n = len(text)
    m = len(pattern)
    lps = compute_lps(pattern)
    positions = []

    i = 0  # Index for text
    j = 0  # Index for pattern

    while i < n:
        if text[i] == pattern[j]:
            i += 1
            j += 1

        if j == m:
            # Found pattern at index i-j
            positions.append(i - j)
            j = lps[j - 1]
        elif i < n and text[i] != pattern[j]:
            if j != 0:
                # Don't match lps[0..j-1] characters, they will match anyway
                j = lps[j - 1]
            else:
                i += 1

    return positions

pattern = "AABA"
print(kmp_search(text, pattern))  # [0, 9, 12]
```

```javascript
function kmpSearch(text, pattern) {
  if (!pattern) return [];

  function computeLPS(pattern) {
    const m = pattern.length;
    const lps = new Array(m).fill(0);
    let length = 0;
    let i = 1;

    while (i < m) {
      if (pattern[i] === pattern[length]) {
        length++;
        lps[i] = length;
        i++;
      } else {
        if (length !== 0) {
          length = lps[length - 1];
        } else {
          lps[i] = 0;
          i++;
        }
      }
    }

    return lps;
  }

  const n = text.length;
  const m = pattern.length;
  const lps = computeLPS(pattern);
  const positions = [];

  let i = 0;
  let j = 0;

  while (i < n) {
    if (text[i] === pattern[j]) {
      i++;
      j++;
    }

    if (j === m) {
      positions.push(i - j);
      j = lps[j - 1];
    } else if (i < n && text[i] !== pattern[j]) {
      if (j !== 0) {
        j = lps[j - 1];
      } else {
        i++;
      }
    }
  }

  return positions;
}
```

**LPS Array Explained:**

```
Pattern: "AABA"

Index:  0  1  2  3
Char:   A  A  B  A
LPS:    0  1  0  1

Meaning:
- LPS[0] = 0 (no proper prefix/suffix)
- LPS[1] = 1 (prefix "A" = suffix "A")
- LPS[2] = 0 (no match)
- LPS[3] = 1 (prefix "A" = suffix "A")

Pattern: "AABAAA"
Index:  0  1  2  3  4  5
Char:   A  A  B  A  A  A
LPS:    0  1  0  1  2  2

At index 4: "AA" prefix = "AA" suffix
At index 5: "AA" prefix = "AA" suffix
```

**How KMP uses LPS:**

```
Text:    "AABAACAADAABAABA"
Pattern: "AABA"
LPS:     [0, 1, 0, 1]

Matching at position 4:
A A B A A C
A A B A     (match first 3)
      x     (mismatch at position 3)

Instead of starting over at position 5:
Use LPS[2] = 0, so restart pattern from beginning
But keep text pointer at position 4!

This is why KMP is O(n + m) - never go backward in text!
```

### 3.3 Rabin-Karp Algorithm

#### 🎯 Core Concept

Use rolling hash for efficient pattern matching. Compare hash values instead of strings.

<details open>
<summary><b>Python</b></summary>

```python
def rabin_karp_search(text: str, pattern: str) -> list[int]:
    """
    Rabin-Karp pattern matching using rolling hash
    Time: O(n + m) average, O(n × m) worst case
    Space: O(1)
    """
    n = len(text)
    m = len(pattern)

    if m > n:
        return []

    # Base for hash (prime number)
    base = 256
    # Modulo for hash (large prime)
    mod = 101

    positions = []
    pattern_hash = 0
    text_hash = 0
    h = 1  # hash multiplier: base^(m-1) % mod

    # Calculate h = base^(m-1) % mod
    for i in range(m - 1):
        h = (h * base) % mod

    # Calculate hash for pattern and first window of text
    for i in range(m):
        pattern_hash = (base * pattern_hash + ord(pattern[i])) % mod
        text_hash = (base * text_hash + ord(text[i])) % mod

    # Slide the pattern over text
    for i in range(n - m + 1):
        # Check if hash matches
        if pattern_hash == text_hash:
            # Hash match! Verify character by character
            if text[i:i+m] == pattern:
                positions.append(i)

        # Calculate hash for next window (rolling hash)
        if i < n - m:
            # Remove leading digit, add trailing digit
            text_hash = (base * (text_hash - ord(text[i]) * h) +
                        ord(text[i + m])) % mod

            # Handle negative hash
            if text_hash < 0:
                text_hash += mod

    return positions
```

```javascript
function rabinKarpSearch(text, pattern) {
  const n = text.length;
  const m = pattern.length;

  if (m > n) return [];

  const base = 256;
  const mod = 101;

  const positions = [];
  let patternHash = 0;
  let textHash = 0;
  let h = 1;

  // Calculate h = base^(m-1) % mod
  for (let i = 0; i < m - 1; i++) {
    h = (h * base) % mod;
  }

  // Calculate initial hashes
  for (let i = 0; i < m; i++) {
    patternHash = (base * patternHash + pattern.charCodeAt(i)) % mod;
    textHash = (base * textHash + text.charCodeAt(i)) % mod;
  }

  // Slide pattern over text
  for (let i = 0; i <= n - m; i++) {
    if (patternHash === textHash) {
      // Verify character by character
      if (text.substring(i, i + m) === pattern) {
        positions.push(i);
      }
    }

    // Calculate next hash
    if (i < n - m) {
      textHash =
        (base * (textHash - text.charCodeAt(i) * h) + text.charCodeAt(i + m)) %
        mod;

      if (textHash < 0) {
        textHash += mod;
      }
    }
  }

  return positions;
}
```

```
Add 'D': hash * 256 + 68
New hash = ((X - 65*h)*256 + 68) mod 101

This is O(1) per slide, not O(m)!
```

```python
def length_of_longest_substring(s: str) -> int:
    """
    Find longest substring without repeating characters
    Time: O(n), Space: O(min(n, m)) where m is charset size
    """
    char_index = {}  # char -> last seen index
    max_length = 0
    left = 0

    for right in range(len(s)):
        char = s[right]

        # If char seen and is in current window
        if char in char_index and char_index[char] >= left:
            # Move left past the duplicate
            left = char_index[char] + 1

        # Update char's last seen index
        char_index[char] = right

        # Update max length
        max_length = max(max_length, right - left + 1)

    return max_length
```

**Given:** Find minimum window in string s that contains all characters of string t

```python
def min_window(s: str, t: str) -> str:
    """
    Find minimum window substring containing all chars of t
    Time: O(n + m), Space: O(m)
    """
    if not s or not t or len(s) < len(t):
        return ""

    from collections import Counter

    # Count required characters
    required = Counter(t)
    needed = len(required)  # Number of unique chars needed

    left = 0
    formed = 0  # Number of unique chars in window with desired frequency
    window_counts = {}

    # Result: (window_length, left, right)
    result = float('inf'), None, None

    for right in range(len(s)):
        char = s[right]
        window_counts[char] = window_counts.get(char, 0) + 1

        # Check if frequency matches
        if char in required and window_counts[char] == required[char]:
            formed += 1

        # Try to contract window
        while left <= right and formed == needed:
            char = s[left]

            # Update result if smaller window found
            if right - left + 1 < result[0]:
                result = (right - left + 1, left, right)

            # Remove from window
            window_counts[char] -= 1
            if char in required and window_counts[char] < required[char]:
                formed -= 1

            left += 1

    return "" if result[0] == float('inf') else s[result[1]:result[2] + 1]

# Examples
print(min_window("ADOBECODEBANC", "ABC"))  # "BANC"
print(min_window("a", "a"))                # "a"
print(min_window("a", "aa"))               # ""
```

```javascript
function minWindow(s, t) {
  if (!s || !t || s.length < t.length) return "";

  const required = new Map();
  for (const char of t) {
    required.set(char, (required.get(char) || 0) + 1);
  }

  const needed = required.size;
  let left = 0;
  let formed = 0;
  const windowCounts = new Map();

  let result = [Infinity, null, null];

  for (let right = 0; right < s.length; right++) {
    const char = s[right];
    windowCounts.set(char, (windowCounts.get(char) || 0) + 1);

    if (required.has(char) && windowCounts.get(char) === required.get(char)) {
      formed++;
    }

    while (left <= right && formed === needed) {
      const char = s[left];

      if (right - left + 1 < result[0]) {
        result = [right - left + 1, left, right];
      }

      windowCounts.set(char, windowCounts.get(char) - 1);
      if (required.has(char) && windowCounts.get(char) < required.get(char)) {
        formed--;
      }

      left++;
    }
  }

  return result[0] === Infinity ? "" : s.substring(result[1], result[2] + 1);
}
```

```python
def compress(chars: list[str]) -> int:
    """
    Compress string in-place
    Time: O(n), Space: O(1)

    Input: ["a","a","b","b","c","c","c"]
    Output: ["a","2","b","2","c","3"]
    Return: 6
    """
    write = 0  # Position to write
    read = 0   # Position to read

    while read < len(chars):
        char = chars[read]
        count = 0

        # Count consecutive characters
        while read < len(chars) and chars[read] == char:
            read += 1
            count += 1

        # Write character
        chars[write] = char
        write += 1

        # Write count if > 1
        if count > 1:
            for digit in str(count):
                chars[write] = digit
                write += 1

    return write
```

```python
def reverse_string(s: list[str]) -> None:
    """
    Reverse string in-place using two pointers
    Time: O(n), Space: O(1)
    """
    left = 0
    right = len(s) - 1

    while left < right:
        # Swap characters
        s[left], s[right] = s[right], s[left]
        left += 1
        right -= 1
```

#### Problem 12: Longest Common Subsequence (LCS)

**Given:** Find length of longest subsequence common to both strings

<details open>
<summary><b>Python</b></summary>

```python
def longest_common_subsequence(text1: str, text2: str) -> int:
    """
    Find longest common subsequence using DP
    Time: O(m × n), Space: O(m × n)

    DP State: dp[i][j] = LCS length of text1[0:i] and text2[0:j]
    """
    m, n = len(text1), len(text2)

    # Create DP table
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    # Fill DP table
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                # Characters match, extend previous LCS
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                # Take max of excluding one character
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    return dp[m][n]

# Examples
print(longest_common_subsequence("abcde", "ace"))   # 3 ("ace")
print(longest_common_subsequence("abc", "abc"))     # 3 ("abc")
print(longest_common_subsequence("abc", "def"))     # 0 (no common)

# With reconstruction of actual subsequence
def longest_common_subsequence_with_string(text1: str, text2: str) -> str:
    """Return the actual LCS string"""
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    # Fill DP table
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    # Reconstruct LCS
    lcs = []
    i, j = m, n
    while i > 0 and j > 0:
        if text1[i-1] == text2[j-1]:
            lcs.append(text1[i-1])
            i -= 1
            j -= 1
        elif dp[i-1][j] > dp[i][j-1]:
            i -= 1
        else:
            j -= 1

    return ''.join(reversed(lcs))

print(longest_common_subsequence_with_string("abcde", "ace"))  # "ace"
```

#### Problem 13: Longest Common Substring

**Given:** Find length of longest common substring (must be contiguous)

```python
def longest_common_substring(text1: str, text2: str) -> int:
    """
    Find longest common substring using DP
    Time: O(m × n), Space: O(m × n)

    DP State: dp[i][j] = LCS length ending at text1[i-1] and text2[j-1]
    """
    m, n = len(text1), len(text2)

    # Create DP table
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    max_length = 0

    # Fill DP table
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                # Extend substring from previous position
                dp[i][j] = dp[i-1][j-1] + 1
                max_length = max(max_length, dp[i][j])
            else:
                # Reset to 0 (substring must be continuous)
                dp[i][j] = 0

    return max_length

                if dp[i][j] > max_length:
                    max_length = dp[i][j]
                    ending_index = i

    # Extract substring
    return text1[ending_index - max_length:ending_index]
```

## 🎤 Top Interview Questions & Answers

### Q1: What's the difference between KMP and Rabin-Karp?

**Perfect Answer:**

> "Both are pattern matching algorithms with O(n+m) time complexity, but they use different approaches:
>
> **KMP (Knuth-Morris-Pratt):**
>
> - Uses preprocessing of pattern to build LPS array
> - Deterministic O(n+m) time in all cases
> - Never goes backward in text
> - Better when pattern has repeating structures
> - No false positives
>
> **Rabin-Karp:**
>
> - Uses rolling hash function
> - Average O(n+m), worst case O(n×m) with hash collisions
> - Simple to implement
> - Excellent for multiple pattern matching
> - Requires verification on hash match (false positives possible)
>
> I'd use KMP for single pattern matching when guaranteed performance matters, and Rabin-Karp for multiple patterns or when simplicity is preferred."

---

### Q2: How do you find all palindromic substrings efficiently?

**Perfect Answer:**

> "There are several approaches with different trade-offs:
>
> **1. Expand Around Center - O(n²):**
>
> - For each position, expand outward while characters match
> - Check both odd-length (single center) and even-length (two centers)
> - Simple and practical for most cases
>
> **2. Manacher's Algorithm - O(n):**
>
> - Linear time but complex to implement
> - Uses previously computed palindrome information
> - Rarely needed in interviews unless explicitly asked
>
> **3. Dynamic Programming - O(n²):**
>
> - Build table: dp[i][j] = is substring s[i:j] palindrome?
> - Uses O(n²) space
> - Good for follow-up queries
>
> For interviews, I'd start with expand-around-center (O(n²)) as it's clean, intuitive, and practical. Only move to Manacher's if specifically asked for O(n) solution."

---

### Q3: Explain the sliding window pattern for substring problems

**Perfect Answer:**

> "The sliding window pattern maintains a window (substring) that slides across the string while tracking relevant state:
>
> **Core components:**
>
> 1. **Two pointers:** left and right define the window
> 2. **State tracking:** usually a hash map for character counts
> 3. **Expansion:** move right pointer to grow window
> 4. **Contraction:** move left pointer to shrink window when needed
>
> **Template:**
>
> ```
> left = 0
> for right in range(len(s)):
>     # Add s[right] to window
>     update_state(s[right])
>
>     # Shrink window if needed
>     while window_invalid():
>         remove_state(s[left])
>         left++
>
>     # Update result with current window
> ```
>
> **When to use:**
>
> - Finding longest/shortest substring with properties
> - Character frequency constraints
> - Problems like 'longest substring without repeating characters'
> - 'minimum window substring'
>
> The key insight is we maintain valid state as we slide, never recalculating from scratch, giving us O(n) time complexity."

---

### Q4: How do you efficiently check if one string is a rotation of another?

**Perfect Answer:**

> "The elegant solution uses a clever property: if s2 is a rotation of s1, then s2 will be a substring of s1+s1.
>
> **Example:**
>
> ```
> s1 = "waterbottle"
> s2 = "erbottlewat"
>
> s1 + s1 = "waterbottlewaterbottle"
>                erbottlewat (s2 is substring!)
> ```
>
> **Implementation:**
>
> ```python
> def is_rotation(s1, s2):
>     if len(s1) != len(s2):
>         return False
>     return s2 in (s1 + s1)
> ```
>
> **Why it works:**
> Any rotation splits s1 into two parts (xy) and swaps them (yx). In s1+s1 = xyxy, we can find yx as a substring.
>
> **Complexity:**
>
> - Time: O(n) using efficient string matching (like KMP internally)
> - Space: O(n) for the concatenated string
>
> This is a great example of transforming a complex problem into a simple substring search!"

### Q5: What's the difference between longest common subsequence and substring?

**Perfect Answer:**

> "The key difference is contiguity:
>
> **Longest Common Subsequence (LCS):**
>
> - Characters must appear in same order but DON'T need to be adjacent
> - Can skip characters in between
> - Example: "abcde" and "ace" → LCS is "ace" (length 3)
>
> **Longest Common Substring:**
>
> - Characters must be contiguous (adjacent)
> - No skipping allowed
> - Example: "abcde" and "ace" → longest substring is just "a", "c", or "e" (length 1)
>
> **DP Difference:**
>
> ```
> Subsequence: dp[i][j] = dp[i-1][j-1] + 1 (if match)
>                        or max(dp[i-1][j], dp[i][j-1])
>
> Substring: dp[i][j] = dp[i-1][j-1] + 1 (if match)
>                      or 0 (reset if no match!)
> ```
>
> The substring DP resets to 0 on mismatch because we need continuous matching characters."

### Q6: When should you reverse a string vs reverse words in a string?

**Perfect Answer:**

> "These are different operations with different use cases:
>
> **Reverse String (character-level):**
>
> - "hello" → "olleh"
> - Uses two pointers from ends
> - O(n) time, O(1) space (in-place)
> - Use case: palindrome checks, reversing individual words
>
> **Reverse Words (word-level):**
>
> - "hello world" → "world hello"
> - Split by whitespace, reverse array of words, join
> - O(n) time, O(n) space
> - Use case: sentence reversal, query processing
>
> **Reverse Each Word:**
>
> - "hello world" → "olleh dlrow"
> - Reverse characters in each word separately
> - Combination of both techniques
>
> In interviews, clarify WHICH reversal they want—the problem statement might be ambiguous!"

## 💡 Pro Tips for Interviews

### 1. **Pattern Recognition**

- Palindrome → Two pointers from ends
- Anagram → Sort or frequency count
- Substring with constraint → Sliding window
- Pattern matching → Consider KMP/Rabin-Karp

### 2. **Common Optimizations**

- Use hash map for O(1) lookups
- Sort when order doesn't matter (anagrams)
- Sliding window often beats nested loops
- ASCII array [26] faster than hash map for letters

### 3. **Edge Cases to Consider**

- Empty string
- Single character
- All same characters
- No solution exists
- Case sensitivity
- Special characters

### 4. **Space-Time Tradeoffs**

- Sorting: O(n log n) time, O(1) extra space
- Hash map: O(n) time, O(n) space
- In-place modification: save space but modify input

### 5. **Interview Communication**

- Start with brute force, then optimize
- Explain time/space complexity
- Draw examples and test cases
- Walk through algorithm step-by-step
- Mention edge cases
