# String Fundamentals - Complete Deep Dive

## 🎯 Key Concepts

### What Are Strings?

**Strings** are sequences of characters used to represent text. In most programming languages, strings are implemented as arrays of characters, but with important differences in behavior and performance characteristics.

**Think of it like this:**

- **Immutable Strings**: "Once created, cannot be changed—any modification creates a new string"
- **Mutable Strings**: "Can modify characters in-place without creating new objects"
- **Character Encoding**: "How characters are stored as numbers (ASCII, Unicode, UTF-8)"
- **String Operations**: "Building blocks like concatenation, slicing, searching"

**Why string knowledge matters:**

- Strings are ubiquitous in programming (30-40% of interview problems)
- Understanding immutability affects time/space complexity
- Character encoding knowledge prevents bugs
- String operations have hidden costs that impact performance

## 1️⃣ String Immutability

### 🎯 Core Concept

**Immutable strings** cannot be modified after creation. Any "modification" creates a new string object.

### Impact on Complexity

<details open>
<summary><b>Python Example - String Concatenation</b></summary>

```python
# ❌ WRONG: O(n²) complexity!
def build_string_wrong(n: int) -> str:
    """
    Build string by repeated concatenation
    Time: O(n²) - creates new string each time!
    """
    result = ""
    for i in range(n):
        result += "a"  # Creates new string each iteration
        # Iteration 1: "" + "a" = "a" (copy 1 char)
        # Iteration 2: "a" + "a" = "aa" (copy 2 chars)
        # Iteration 3: "aa" + "a" = "aaa" (copy 3 chars)
        # Total: 1 + 2 + 3 + ... + n = O(n²)
    return result

# ✅ CORRECT: O(n) complexity
def build_string_correct(n: int) -> str:
    """
    Build string using list (mutable)
    Time: O(n)
    """
    result = []  # List is mutable
    for i in range(n):
        result.append("a")  # O(1) append
    return "".join(result)  # O(n) join once

# Comparison
import time

# Wrong way
start = time.time()
build_string_wrong(10000)
print(f"Wrong way: {time.time() - start:.3f}s")  # ~0.5s

# Correct way
start = time.time()
build_string_correct(10000)
print(f"Correct way: {time.time() - start:.3f}s")  # ~0.001s
```

</details>

<details>
<summary><b>JavaScript Example</b></summary>

```javascript
console.timeEnd("Correct");
```

</details>

<details>
<summary><b>Java Example - StringBuilder</b></summary>

```java
// ❌ WRONG: O(n²) with String
public String buildStringWrong(int n) {
    String result = "";
    for (int i = 0; i < n; i++) {
        result += "a";  // Creates new String object each time
    }
    return result;
}

// ✅ CORRECT: O(n) with StringBuilder
public String buildStringCorrect(int n) {
    StringBuilder result = new StringBuilder();
    for (int i = 0; i < n; i++) {
        result.append("a");  // Modifies internal buffer
    }
    return result.toString();  // Convert once at end
}
```

</details>

**Key Takeaway:**

```
Immutable strings:
  - Each modification creates a new object
  - O(n) to create each new string
  - n modifications = O(n²) total

Mutable structures (list/StringBuilder):
  - Modify in-place or amortized O(1) append
  - n modifications = O(n) total
  - Convert to string once at end: O(n)
```

## 2️⃣ Character Encoding

### 🎯 ASCII vs Unicode vs UTF-8

#### ASCII (American Standard Code for Information Interchange)

```
Standard ASCII: 0-127 (7 bits)
Extended ASCII: 0-255 (8 bits)

Common values:
'0'-'9': 48-57
'A'-'Z': 65-90
'a'-'z': 97-122
' ': 32
'\n': 10
'\0': 0 (null terminator in C)
```

<details open>
<summary><b>ASCII Examples</b></summary>

```python
# Character to ASCII
print(ord('A'))  # 65
print(ord('a'))  # 97
print(ord('0'))  # 48

# ASCII to character
print(chr(65))   # 'A'
print(chr(97))   # 'a'

# Case conversion using ASCII
def to_upper(c: str) -> str:
    """Convert lowercase to uppercase using ASCII"""
    if 'a' <= c <= 'z':
        return chr(ord(c) - 32)  # 'a'=97, 'A'=65, diff=32
    return c

def to_lower(c: str) -> str:
    """Convert uppercase to lowercase using ASCII"""
    if 'A' <= c <= 'Z':
        return chr(ord(c) + 32)
    return c

print(to_upper('a'))  # 'A'
print(to_lower('Z'))  # 'z'

# Check if alphanumeric
def is_alphanumeric(c: str) -> bool:
    """Check if character is alphanumeric"""
    return ('0' <= c <= '9') or ('A' <= c <= 'Z') or ('a' <= c <= 'z')

print(is_alphanumeric('5'))  # True
print(is_alphanumeric('a'))  # True
print(is_alphanumeric('!'))  # False
```

</details>

#### Unicode

```
Unicode: Universal character encoding
- Covers all world languages
- Code points: U+0000 to U+10FFFF
- ASCII is subset (U+0000 to U+007F)

Examples:
'A' = U+0041
'α' (alpha) = U+03B1
'中' (Chinese) = U+4E2D
'😀' (emoji) = U+1F600
```

#### UTF-8 Encoding

```
UTF-8: Variable-length encoding of Unicode
- 1 byte: ASCII (0-127)
- 2 bytes: Most European languages
- 3 bytes: Most Asian languages
- 4 bytes: Emojis, rare characters

Character 'A':
  Unicode: U+0041
  UTF-8: 0x41 (1 byte)

Character '中':
  Unicode: U+4E2D
  UTF-8: 0xE4 0xB8 0xAD (3 bytes)
```

### Basic Operations

| Operation       | Python      | JavaScript  | Complexity | Notes                          |
| --------------- | ----------- | ----------- | ---------- | ------------------------------ |
| Access char     | s[i]        | s[i]        | O(1)       | Direct indexing                |
| Length          | len(s)      | s.length    | O(1)       | Stored as attribute            |
| Concatenation   | s1 + s2     | s1 + s2     | O(n)       | Creates new string             |
| Slice/Substring | s[i:j]      | s.slice()   | O(k)       | k = length of substring        |
| Find substring  | s.find()    | s.indexOf() | O(n×m)     | Naive search, n=len, m=pattern |

| Split           | s.split()   | s.split()   | O(n)       | Creates list/array             |
| Join            | ''.join()   | arr.join()  | O(n)       | n = total chars                |

### String Concatenation Deep Dive

<details open>
<summary><b>Python - Different Concatenation Methods</b></summary>

```python
import time

n = 10000

# Method 1: += operator (SLOW - O(n²))
start = time.time()
result = ""
for i in range(n):
    result += "a"
time1 = time.time() - start

# Method 2: List + join (FAST - O(n))
start = time.time()

result = "".join(result)
time2 = time.time() - start

# Method 3: List comprehension + join (FASTEST - O(n))
start = time.time()
result = "".join(["a" for _ in range(n)])
time3 = time.time() - start

# Method 4: Multiplication (BUILT-IN - O(n))
start = time.time()
result = "a" * n
time4 = time.time() - start

print(f"Method 1 (+=):        {time1:.4f}s")  # ~0.5s
print(f"Method 2 (list+join): {time2:.4f}s")  # ~0.001s
print(f"Method 3 (comprehension): {time3:.4f}s")  # ~0.0008s
print(f"Method 4 (multiply):  {time4:.4f}s")  # ~0.00001s

# ✅ Best practice: Use built-in when possible, list+join otherwise
```

## 4️⃣ String Comparison & Equality

### Comparison Rules

<details open>
<summary><b>Lexicographic Comparison</b></summary>

```python
# Lexicographic (dictionary) order
print("apple" < "banana")  # True (a < b)
print("apple" < "application")  # True (shorter comes first)
print("Apple" < "apple")  # True (uppercase < lowercase in ASCII)

# Character-by-character comparison
def compare_strings(s1: str, s2: str) -> int:
    """
    Compare two strings lexicographically
    Returns: -1 if s1 < s2, 0 if equal, 1 if s1 > s2
    """
    min_len = min(len(s1), len(s2))

    for i in range(min_len):
        if s1[i] < s2[i]:
            return -1
        elif s1[i] > s2[i]:
            return 1

    # If one is prefix of other
    if len(s1) < len(s2):
        return -1
    elif len(s1) > len(s2):
        return 1
    return 0

print(compare_strings("apple", "banana"))  # -1
print(compare_strings("apple", "apple"))   # 0
print(compare_strings("banana", "apple"))  # 1

# Case-insensitive comparison
s1 = "Hello"
s2 = "HELLO"
print(s1 == s2)  # False
print(s1.lower() == s2.lower())  # True
```

</details>

<details open>

```python
s = "Hello, World!"

# Basic slicing
print(s[0:5])    # 'Hello' (indices 0,1,2,3,4)

print(s[-6:])    # 'World!' (from 6th last to end)

# Out of bounds slicing (doesn't raise error)
print(s[100:200])  # '' (empty string)
print(s[-100:5])   # 'Hello' (clips to valid range)

# Common patterns
def get_first_n(s: str, n: int) -> str:
    """Get first n characters"""
    return s[:n]

def get_last_n(s: str, n: int) -> str:
    """Get last n characters"""
    return s[-n:]

def remove_first_n(s: str, n: int) -> str:
    """Remove first n characters"""
    return s[n:]

def remove_last_n(s: str, n: int) -> str:
    """Remove last n characters"""
    return s[:-n] if n > 0 else s

print(get_first_n(s, 5))     # 'Hello'
print(get_last_n(s, 6))      # 'World!'
print(remove_first_n(s, 7))  # 'World!'
print(remove_last_n(s, 7))   # 'Hello'
```

```javascript
console.log(padLeft("42", 5)); // '   42'
```

</details>

## 🎤 String Fundamentals Interview Questions

### Q1: What's the difference between mutable and immutable strings?

**Perfect Answer:**

> "Immutable strings, like in Python and JavaScript, cannot be modified after creation. Any 'modification' creates a new string object. This affects complexity:
>
> For example, concatenating strings in a loop:
>
> ```python
> result = ""
> for i in range(n):
>     result += "a"  # O(n²) - creates new string each time
> ```
>
> Each concatenation copies all previous characters plus the new one, giving us 1+2+3+...+n = O(n²) operations.
>
> Instead, we should use a list (mutable) and join once:
>
> ```python
> result = []
> for i in range(n):
>     result.append("a")  # O(1) amortized
> final = "".join(result)  # O(n)
> ```
>
> This is O(n) total. In Java, we'd use StringBuilder for the same reason.
>
> Mutable strings (like C++ std::string) allow in-place modification, so character updates are O(1) without creating new objects."

---

### Q2: Explain character encoding (ASCII vs Unicode vs UTF-8)

**Perfect Answer:**

> "ASCII is the original 7-bit encoding (0-127) covering English letters, digits, and basic symbols. Extended ASCII uses 8 bits (0-255) but still limited.
>
> Unicode was created to represent all world languages. It assigns a unique code point (U+0000 to U+10FFFF) to every character. ASCII is a subset—'A' is both ASCII 65 and Unicode U+0041.
>
> UTF-8 is a way to encode Unicode efficiently:
>
> - ASCII characters (0-127): 1 byte (backward compatible)
> - Most European: 2 bytes
> - Most Asian: 3 bytes
> - Emojis: 4 bytes
>
> For example, 'Hello 世界':
>
> - 'Hello' = 5 bytes (ASCII)
> - '世界' = 6 bytes (3 each)
> - Total: 11 bytes, but only 7 characters
>
> This matters for interview problems—when calculating space complexity or working with substrings, we need to understand character vs byte length."

---

### Q3: Why is string concatenation slow in Python?

**Perfect Answer:**

> "In Python, strings are immutable. When you do `s = s + "a"`, Python:
>
> 1. Creates a new string object with room for existing + new characters
> 2. Copies all existing characters to the new object
> 3. Adds the new character
> 4. Updates the reference to point to new object
> 5. Garbage collects the old object
>
> In a loop doing this n times:
>
> ```
> Iteration 1: Copy 0 chars + add 1 = 1 operation
> Iteration 2: Copy 1 char + add 1 = 2 operations
> Iteration 3: Copy 2 chars + add 1 = 3 operations
> ...
> Total: 1+2+3+...+n = n(n+1)/2 = O(n²)
> ```
>
> The solution is using a list (mutable) for O(1) appends, then join once at the end:
>
> ```python
> result = []
> for i in range(n):
>     result.append("a")  # O(1) amortized
> return "".join(result)  # O(n)
> ```
>
> This is O(n) total because we only copy all characters once during join."
